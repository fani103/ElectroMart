## 📖 Overview

This repository contains the **Week 3 assignment** for the InternNova Web Development Internship — a deep dive into **JavaScript Fundamentals**. It covers core language concepts through six structured tasks, wrapped in an **interactive, browser-based console** so every program can be run and viewed without opening DevTools.

> 💡 **Highlight:** Instead of plain script files, this project ships with a live in-page console — click **Run ▸** on any task card and watch the output stream in, right on the page.

## 🚀 Getting Started

No installation, no build step — just open and run.

1. **Clone the repo**
   ```bash
   git clone https://github.com/fani103/Magic.git
   cd Magic
   ```
2. **Open `index.html`** in any modern browser (double-click it, or use an extension like _Live Server_ in VS Code).
3. Click **▶ Run All Tasks**, or run any task individually — output appears instantly in the on-page console.

Prefer the terminal? Every task also runs standalone with Node:

```bash
node -e "$(cat utils.js) $(cat task1_basics.js)"
```
