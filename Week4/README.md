## 📖 Overview

Week 4 of the InternNova Web Development Internship builds directly on Week 3 — moving from language basics into the tools that make JavaScript actually *do* things on a webpage: **functions, arrays, objects, DOM manipulation, and events.**

The project is split into two experiences:
- **Tasks 1–3** (Functions, Arrays, Objects) stream their output into a **live on-page console** — no DevTools needed.
- **Tasks 4–6** (DOM, Events, Mini Project) are **fully interactive** — real buttons, real inputs, real elements changing live on the page.

## 🚀 Getting Started

```bash
git clone https://github.com/fani103/Magic.git
cd Magic
```

Open `index.html` in any modern browser (or use a Live Server extension). Then:

1. Click **Run Tasks 1–3** to see functions, arrays, and objects log their output.
2. Scroll to the **DOM Playground** and click each button to watch real page elements change.
3. Try the **Events Playground** — click the counter, type in the live-preview box, submit the form, hover the box, and type into the keyboard demo.
4. Use the **To-Do List** at the bottom — add a task, check it off, delete it, and filter by status.
